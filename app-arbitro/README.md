# App arbitro (Android)

App per il telefono dell'arbitro di **strongmanitalia Gara**.
Cerca da sola il PC della gara sul Wi-Fi e apre la schermata arbitro senza browser.

- L'APK viene creato da GitHub Actions a ogni modifica di questa cartella
  e pubblicato nella pagina **Releases** del repository (release "App arbitro").
- Funziona con il programma strongmanitalia Gara per PC dalla versione del 8/11/2026
  (che risponde alla ricerca sulla porta UDP 4170).
- Se la ricerca non trova il PC, si può scrivere l'indirizzo a mano (es. `192.168.1.20:4173`).
